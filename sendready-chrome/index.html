メール、チャット、SNS、ドキュメント、問い合わせフォーム ── テキスト入力があるすべてのサイトでSendReadyが使えます。

「この言い方で大丈夫かな…」と、送信前に手が止まる。

敬語に直す、英語に訳す、長文を要約する、返信を考える ──

How it works

コピペ往復は、もう不要。4ステップで完了

別タブのAIに貼り付ける手間ゼロ。いまの入力欄の上で完結します。

1

テキストを選択 / 入力

変換したい文章を選択、または入力欄でトリガーを打つ

2

起動する

選択ツールバー・右クリック・ショートカットのいずれかで

3

AIが変換 / 展開

丁寧語・翻訳・要約・返信に変換。定型文はその場で展開

4

適用 / コピー

ワンタップで入力欄へ反映。読み取り専用ならコピー

Selection toolbar

選択するだけで、
変換メニューが出る。

文章を選ぶと、選択のすぐ近くに丸いアイコンが出現。タップすればAIプリセットのメニューが開き、選ぶだけで変換が始まります。

  • 選択付近に出る軽量ランチャー（暗幕なし）
  • 丁寧に・翻訳・要約・誤字修正をワンタップ
  • スクロール・Esc・外側クリックでサッと消える
Inline trigger

入力欄で打って、Enter。
それだけ。

//en 文章 のように前置トリガー＋文章を書いてEnter。AIが変換し、結果をオーバーレイで確認 → 「適用」でその場に置き換えます。手を止めずに変換できます。

  • 現在行からトリガーを検出して以降を変換
  • Enterは消費され、改行・送信されない
  • IME変換中（日本語入力の確定前）は誤発火しない
Reply

受け取った文を選んで、
返信を生成。

相手のメッセージを選択して「↩ 返信を作成」。選んだ文を「受け取ったメッセージ」とみなし、AIが返信文を作成します。文体を選び、必要なら一言指示するだけ。

  • 丁寧・カジュアルなど文体を選べる
  • 結果はコピーして好きな返信欄へ
  • 選択した相手の文は書き換えない
Snippets

よく使う文章は、
トリガーで一瞬。

署名や定型あいさつを ;sig のようなトリガーに登録。入力欄で打ってスペース／Tab／Enterで確定すると、登録テキストへ即展開します。AIを呼ばないので回数無制限・即時です。

  • AI呼び出しなしで瞬時に展開・回数無制限
  • 確定キーが必要なので打鍵途中で誤爆しない
  • 本文は1000文字まで、最大10件登録
Features

搭載機能

AI変換と定型文。2つのエンジンで、書く・直す・返すを速くします。

🤖

AI変換プリセット

「丁寧に」「英語に翻訳」「要約」「誤字脱字を修正」を最初から搭載。選択して選ぶか //p などのトリガー＋Enterで即変換。最大10件まで自分用に追加でき、指示は200文字まで。

⚡

定型文スニペット

;sig のようなトリガーを打って区切りで確定すると登録テキストへ即展開。AI呼び出しなしで回数無制限。本文1000文字・最大10件。

↩️

返信を作成

受け取った文章を選ぶとAIが返信文を生成。文体を選んでひと言指示するだけ。結果はコピーして好きな欄へ貼れます。

🎯

3つの起動方法

選択ツールバー・右クリックメニュー・ショートカット（Alt+Shift+S）。入力欄ではトリガーだけでも起動。手を止めません。

📝

あらゆる入力欄に対応

input・textarea・contenteditable に対応し、結果はその場の入力欄へ直接反映。React製の入力欄でも正しく置換し、読み取り専用は自動でコピー。

🌏

11言語対応・ダーク対応

UIは主要11言語＋AUTOに対応。ブラウザ言語に自動追従し、アラビア語はRTL表示。テーマは自動・ライト・ダークから選べます。

How it works in detail

使い方としくみ

3つの機能それぞれの流れと、知っておくと便利な仕様をまとめました。

AI変換

整える・訳す・要約する

  1. 1文章を選択してメニューから選ぶ、または入力欄で //p 文章 のように前置トリガー＋文章を書く
  2. 2Enterで発火。現在行からトリガーを検出し、それ以降を変換対象としてAIへ送信
  3. 3結果がオーバーレイ表示。「適用」で入力欄を置換、または「コピー」「再生成」
定型文

登録テキストを即展開

  1. 1入力欄でトリガー（例 ;sig）を打つ
  2. 2スペース／Tab／Enterで確定すると登録テキストへ即置換（AI呼び出しなし）
  3. 3確定キーが必要なので、打鍵途中で誤って展開されません
返信

もらった文に返事を作る

  1. 1相手のメッセージを選択 → 右クリック「↩ 返信を作成」かパレットの返信欄から起動
  2. 2文体を選び、必要なら一言だけ指示（任意）
  3. 3返信文が生成されコピー。選択した相手の文は書き換えません

Privacy & Safety

送るのは、あなたが選んだ一文だけ。

プライバシーファーストで設計しています。ページ全体を読み取ったりはしません。

🔒 設定はローカル保存

プリセット・テーマ・言語などの設定はブラウザ内（chrome.storage）に保存。あなたのアカウントに紐づく形で外部に蓄積しません。

🤖 AIに送るのは対象テキストだけ

変換のためにAIへ送られるのは、あなたが選択・入力した対象テキストのみ。ページの他の内容や閲覧履歴は送信しません。

🛡️ 必要最低限の権限

テキストの読み書きとAIプロキシへの通信に必要な権限のみ。カメラ・マイク・位置情報などは一切要求しません。

🎉 登録不要・無料

アカウント登録もAPIキーも不要。AI変換は1日50回まで無料、定型文の展開は回数無制限で使えます。
