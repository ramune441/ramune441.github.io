기능

기능

AI 변환과 문구 — 더 빠르게 쓰고, 고치고, 답장하는 두 가지 엔진.

🤖

AI 프리셋

다듬기, 번역, 요약, 오타 수정을 기본 제공합니다. 선택해서 고르거나 //p 같은 트리거 + Tab으로 변환하세요. 나만의 프리셋을 최대 10개까지 추가할 수 있습니다(지시문 200자까지).

⚡

문구

;sig 같은 트리거를 입력하고 확정하면 저장해 둔 텍스트가 즉시 펼쳐집니다. AI 없이 무제한 사용. 최대 1,000자, 문구 10개.

↩️

답장 작성

받은 메시지를 선택하면 AI가 답장 초안을 써 줍니다. 말투를 고르고 간단한 힌트를 더한 뒤, 어디든 복사해 쓰세요.

🎯

3가지 실행 방법

선택 툴바, 우클릭 메뉴, 또는 단축키(Alt+Shift+S). 입력창에서는 트리거만으로도 실행됩니다. 흐름을 끊지 않습니다.

📝

모든 텍스트 입력창

이메일, 채팅, SNS, 문서 — 입력할 수 있는 곳이라면 어디든. 다듬은 텍스트가 입력창에 바로 들어갑니다. 읽기 전용 텍스트는 자동으로 복사됩니다.

🌏

11개 언어 · 다크 모드

인터페이스는 11개 언어를 지원하며 브라우저 언어에 자동으로 맞춥니다. 밝은 테마와 어두운 테마도 고를 수 있습니다.

개인정보 보호와 안전

선택한 텍스트만 브라우저를 떠납니다.

프라이버시 우선으로 설계했습니다. 페이지 전체를 읽지 않습니다.

🔒 설정은 로컬에 저장

직접 만든 프리셋과 설정은 브라우저 안에만 저장됩니다 — 외부 서버에 수집하지 않습니다.

🤖 AI에는 대상 텍스트만

변환을 위해 AI로 보내지는 것은 선택하거나 입력한 텍스트뿐입니다. 페이지의 나머지 내용과 기록은 보내지 않습니다.

🛡️ 최소한의 권한

텍스트를 읽고 쓰고 AI 프록시에 연결하는 데 필요한 권한만 사용합니다. 카메라, 마이크, 위치 정보에는 접근하지 않습니다.

🎉 무료, 가입 불필요

계정이나 API 키가 필요 없습니다. AI 변환은 하루 50회까지 무료이고, 문구 펼치기는 무제한입니다.

FAQ

자주 묻는 질문

네, 완전 무료입니다. API 키나 계정이 필요 없습니다. AI 변환은 하루 50회까지 무료이고, 문구 펼치기는 무제한입니다. 숨은 비용도 없습니다.
AI 변환은 텍스트를 정중하게 바꾸거나 번역, 요약하는 등 다시 써 주는 기능입니다. 문구는 서명이나 인사말처럼 정해진 텍스트를 그대로 넣어 주며, AI를 쓰지 않으므로 즉시 펼쳐지고 언제나 무료입니다.
프리셋과 설정은 브라우저 안에 저장됩니다. AI로 보내지는 것은 변환하려고 선택한 텍스트뿐이며, 페이지의 나머지 내용이나 검색 기록은 보내지 않습니다. 삭제하면 저장된 데이터도 함께 지워집니다.
Chrome 확장 프로그램이라 데스크톱용 Google Chrome이 필요합니다. 모바일 Chrome에서는 작동하지 않습니다. Android용으로는 별도의 SendReady 앱을 제공합니다.
