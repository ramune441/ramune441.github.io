SendReady
사용법

복사·붙여넣기 왕복은 이제 그만. 4단계로 끝.

다른 AI 탭에 붙여 넣을 필요 없이, 지금 입력창에서 바로 끝납니다.

1
✏️

선택 또는 입력

텍스트를 드래그하거나, 입력창에 트리거를 입력하세요

2

실행하기

선택 툴바, 우클릭, 또는 단축키로

3
🎚️

AI가 변환 또는 펼침

다듬기, 번역, 요약, 답장 — 또는 문구를 펼치기

4
✅

적용하기

한 번 누르면 입력창에 들어갑니다 — 읽기 전용 텍스트는 복사됩니다

🤖AI로 변환

  1. 문장을 선택
  2. SendReady 아이콘 클릭
  3. 문체 선택(직접 입력도 가능)
  4. 변환 누르기
  5. 적용으로 그 자리에 교체

↩️답장 작성

  1. 받은 메시지 선택 → 클릭
  2. ↩ 답장 작성 체크
  3. 문체 고르고 요점 입력
  4. 답장 생성 → 복사

🪄키보드 트리거(문체도 지정)

  1. AI 트리거: //p 문장 입력 후 Tab → 그 문체로 변환
  2. 스니펫 트리거: ;sig 입력 후 Tab → 스니펫 펼치기

⚡입력란에서 스니펫 삽입

  1. 입력란 클릭
  2. 나타난 SendReady 아이콘 클릭
  3. 목록에서 스니펫 선택
  4. 입력란에 삽입됨
실행

여는 방법은 여러 가지

선택 툴바 — 텍스트를 선택하면 나오는 아이콘 클릭.
🖱️ 우클릭 메뉴 — 선택 후 우클릭 → SendReady 가 팔레트를 엽니다.
⌨️ 단축키 — Alt+Shift+S로 팔레트 열기.
입력란 아이콘 — 입력란을 클릭해 아이콘을 띄우고 스니펫 삽입.
