SendReady
使い方

コピペ往復は、もう不要。4ステップで完了

別タブのAIに貼り付ける手間ゼロ。いまの入力欄の上で完結します。

1
✏️

テキストを選択 / 入力

変換したい文章を選択、または入力欄でトリガーを打つ

2

起動する

選択ツールバー・右クリック・ショートカットのいずれかで

3
🎚️

AIが変換 / 展開

丁寧語・翻訳・要約・返信に変換。定型文はその場で展開

4
✅

反映する

ワンタップで入力欄に反映。コピーだけの文章はコピー

🤖AIで変換

  1. 文章を選択
  2. SendReady アイコンをクリック
  3. 文体を選ぶ(自分で入力もOK)
  4. 変換を押す
  5. 適用でその場に置き換え

↩️返信を作る

  1. 受け取った文章を選択 → をクリック
  2. ↩ 返信を作成にチェック
  3. 文体を選び、返したい内容を書く
  4. 返信を生成 → コピー

🪄キーボードのトリガー(文体も指定できる)

  1. AIトリガー: //p 文章 と書いて Tab → その文体で変換
  2. 定型文トリガー: ;sig を打って Tab → 定型文を展開

⚡入力欄から定型文を挿入

  1. 入力欄をクリック
  2. 出てきた SendReady アイコンをクリック
  3. 一覧から定型文を選ぶ
  4. 本文に挿入される
起動

起動方法はいくつかあります

選択ツールバー — 文章を選ぶと出るアイコンをクリック。
🖱️ 右クリックメニュー — 選択して右クリック → SendReady でパレットを開く。
⌨️ ショートカット — Alt+Shift+S でパレットを開く。
入力欄のアイコン — 入力欄をクリックして出るアイコンから定型文を挿入。
