SendReady Privacy Policy

Last updated: June 2025

This Privacy Policy describes how the developer Ramune (the "Developer") handles user information in the Chrome extension "SendReady" (the "Extension"). The Extension is a tool that uses AI to transform text that the user selects or types.

1. Information We Collect

The Extension is designed with privacy first, and handles only the minimum information necessary to provide its features.

(1) Settings stored locally

  • The contents of your presets (transformation rules)
  • App settings such as theme and language

This information is stored only on the user's device using the Chrome Storage API (chrome.storage.sync / chrome.storage.local).

(2) Device identifier (deviceId)

  • On first use, the Extension generates a deviceId in the form "chrome:" + a random UUID and stores it in chrome.storage.local.
  • This deviceId is used solely to manage AI usage counts (the daily usage limit), and is not linked to any personal information such as your name or email address.

2. Information Sent to AI

The Extension sends only the text you select or type as the transformation target to the AI (Google Gemini), via a Cloudflare Worker operated by the Developer (https://sendready-1-22.warload57.workers.dev), and retrieves the transformed result.

Important: No other page content, browsing history, or personal information is sent. Only the text you explicitly designate for transformation is transmitted.

To manage the usage limit (50 times per day) and to prevent abuse, the deviceId and IP address are used during the above communication.

3. Third-Party Sharing

The Developer never sells or provides your personal data to anyone other than the service providers required to perform the AI processing described above (Cloudflare and Google Gemini).

The Extension uses no advertising, tracking, or analytics whatsoever.

For how data is handled by Google Gemini, please see the Gemini API Terms of Service and the Google Privacy Policy.

4. Permissions

The Extension uses the following Chrome permissions. Each is the minimum required to provide its features.

  • storage: Storing presets, settings, and the deviceId
  • contextMenus: Running transformations from the right-click menu
  • clipboardWrite: Copying transformation results to the clipboard
  • activeTab: Reading the text currently selected in the active tab
  • scripting: Inserting and applying transformation results into the page
  • host_permissions (AI proxy): Communicating with the Cloudflare Worker above

The Extension does not request access to your camera, microphone, or location.

5. Data Storage and Deletion

All data the Extension stores (settings, presets, and the deviceId) is kept solely on the user's device (in Chrome's storage area). The Developer does not independently collect or store this data.

You can delete all stored data by uninstalling the Extension.
