SendReady プライバシーポリシー

最終更新: 2025年6月

本プライバシーポリシーは、開発者 Ramune（以下「当開発者」）が提供する Chrome 拡張機能「SendReady」（以下「本拡張機能」）における、利用者情報の取扱いについて定めるものです。本拡張機能は、ユーザーが選択・入力したテキストを AI で変換するためのツールです。

1. 収集する情報について

本拡張機能は、プライバシーを最優先に設計されており、機能の提供に必要な最小限の情報のみを取り扱います。

(1) ローカルに保存される設定情報

  • プリセット（変換ルール）の内容
  • テーマ、言語などのアプリ設定

これらの情報は、Chrome の Storage API（chrome.storage.sync / chrome.storage.local）を利用して、ユーザーの端末内にのみ保存されます。

(2) デバイス識別子（deviceId）

  • 本拡張機能は、初回利用時に "chrome:" + ランダムな UUID 形式の deviceId を生成し、chrome.storage.local に保存します。
  • この deviceId は、AI 利用回数の管理（1日あたりの利用上限）にのみ使用され、氏名・メールアドレス等の個人情報とは紐付きません。

2. AI に送信される情報について

本拡張機能は、ユーザーが変換対象として選択または入力したテキストのみを、当開発者が運用する Cloudflare Worker（https://sendready-1-22.warload57.workers.dev）を経由して AI（Google Gemini）に送信し、変換結果を取得します。

重要：ページのその他の内容、閲覧履歴、個人情報が送信されることはありません。送信されるのは、ユーザーが明示的に変換対象とした文字列のみです。

利用回数制限（1日あたり50回）の管理および不正利用の防止のため、上記通信の際に deviceId と IP アドレスが利用されます。

3. 第三者への提供について

当開発者は、上記の AI 処理を実現するための委託先（Cloudflare および Google Gemini）以外に、ユーザーの個人データを販売・提供することは一切ありません。

本拡張機能は、広告・トラッキング・アナリティクスを一切利用しません。

Google Gemini におけるデータの取扱いについては、Gemini API 利用規約および Google プライバシーポリシーをご参照ください。

4. 権限について

本拡張機能は、以下の Chrome 権限を使用します。いずれも機能の実現に必要最小限のものです。

  • storage: プリセット・設定・deviceId の保存
  • contextMenus: 右クリックメニューからの変換実行
  • clipboardWrite: 変換結果のクリップボードへのコピー
  • activeTab: 現在のタブで選択中のテキストの取得
  • scripting: 変換結果のページへの挿入・反映
  • host_permissions（AI プロキシ）: 上記 Cloudflare Worker への通信

本拡張機能は、カメラ・マイク・位置情報を要求しません。

5. データの保存・削除について

本拡張機能が保存するデータ（設定・プリセット・deviceId）は、すべてユーザーの端末内（Chrome のストレージ領域）に限定されます。当開発者がこれらのデータを独自に収集・保存することはありません。

ユーザーは、本拡張機能をアンインストールすることで、保存されたすべてのデータを削除できます。
