사용 가이드

프로필을 한 번 저장하고 AI로 가입, 문의, 주문 양식을 작성하세요. 계정이나 API 키 없이 무료로 사용할 수 있습니다.

일일 사용 한도가 있습니다. AI가 잘못 판단하거나 일부 사용자 지정 양식 요소에 입력하지 못할 수 있습니다. 결과를 꼭 확인하세요. FormPilot은 양식을 자동 제출하지 않습니다.

사용 가이드
  1. 프로필 등록하기: 이름, 연락처, 주소를 프로필에 저장합니다. 프로필은 최대 10개, 프로필별 사용자 지정 필드는 최대 50개까지 저장합니다.
  2. AI 자동 입력 실행: 양식을 열고 프로필을 선택한 뒤 AI 자동 입력 버튼을 누릅니다.
  3. AI 자동 입력 실행: 입력 결과를 확인하고 양식은 직접 제출합니다.
  4. 폼 데이터 저장 및 복원: 현재 양식 저장 → 저장 · 지금 이 페이지에 입력된 내용을 저장합니다 (나중에 복원 가능)
  5. 폼 데이터 저장 및 복원: 복원 · 저장한 내용을 이 페이지 양식에 다시 입력합니다
  6. 폼 데이터 저장 및 복원: "회원 가입" 복원 완료 (6개 필드) · 입력 결과를 확인하고 양식은 직접 제출합니다.

1 · 프로필 등록하기

이름, 연락처, 주소를 프로필에 저장합니다.

  1. 프로필 → + · 프로필을 추가합니다 (최대 10개)
  2. 양식 입력에 사용할 정보를 등록·수정하는 화면
  3. 추가 필드 · 항목 이름. 양식의 라벨과 비슷하게 쓰면 더 잘 맞습니다 · 그 항목에 입력할 값 · 추가 필드를 한 줄 늘립니다 (최대 50개)
  4. 저장

프로필은 최대 10개, 프로필별 사용자 지정 필드는 최대 50개까지 저장합니다.

프로필 등록하기 · FormPilot

2 · AI 자동 입력 실행

  1. 양식을 열고 프로필을 선택한 뒤 AI 자동 입력 버튼을 누릅니다.
  2. 이미 입력된 필드 건너뛰기 · 이미 값이 있는 칸은 그대로 두고 빈 칸만 입력합니다
  3. 취소 · 실행 중인 자동 입력을 중단합니다
  4. 입력 결과를 확인하고 양식은 직접 제출합니다.

저장한 프로필 값은 기기에 보관합니다. AI에는 양식 라벨, 필드 속성, 사용자 지정 필드 이름을 분석용으로 전송하며 저장한 프로필 값은 보내지 않습니다.

AI 자동 입력 실행 · FormPilot

3 · 폼 데이터 저장 및 복원

사이트별 입력 내용을 저장하고 다음 방문 때 복원합니다.

  1. 현재 양식 저장 → 저장
  2. URL 시작 · URL이 이 문자열로 시작하는 모든 페이지에 표시됩니다 (? 뒤의 매개변수는 무시). 짧게 줄이면 더 많은 페이지에 적용됩니다
  3. 복원 · 저장한 내용을 이 페이지 양식에 다시 입력합니다

사이트당 최대 20건, 총 50개 사이트까지 저장할 수 있습니다. 한도를 초과하면 오래된 데이터부터 자동 삭제됩니다.

폼 데이터 저장 및 복원 · FormPilot

4 · 키보드 단축키

어느 페이지에서든 이 키를 누르면 이 프로필로 입력합니다

  1. 프로필 → 단축키 → 변경
  2. 키를 누르세요 (Esc로 취소)
  3. Ctrl, Alt, Cmd 중 하나 + 원하는 키 (예: Alt+Shift+1)
  4. 사용 불가: Esc, Tab, Ctrl+Tab 등 브라우저가 쓰는 키
  5. 해제 · 이 프로필의 단축키를 없앱니다

개인정보처리방침

저장한 프로필 값은 기기에 보관합니다. AI에는 양식 라벨, 필드 속성, 사용자 지정 필드 이름을 분석용으로 전송하며 저장한 프로필 값은 보내지 않습니다.

AI 분석은 Cloudflare Workers 프록시를 통해 Google Gemini를 사용합니다. 기기 식별자와 IP 주소는 일일 한도와 오용 방지에 사용됩니다. 사용 횟수와 서버 로그는 저장된 프로필과 별도로 처리됩니다.

이 웹사이트는 Google Analytics를 사용합니다. 문의 양식을 보내면 메시지, 선택한 이메일과 첨부 파일이 개발자에게 전달됩니다. 삭제 후 설문은 선택 사항이며 사용 진단 정보를 포함할 수 있습니다.

확장 프로그램을 삭제하면 기기의 프로필·저장 양식·설정이 삭제됩니다. 서버의 사용 횟수와 오용 기록은 자동으로 삭제되지 않습니다.
