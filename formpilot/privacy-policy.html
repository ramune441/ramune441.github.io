Privacy Policy

Last updated: June 27, 2026

1. Introduction

This Privacy Policy describes how the Chrome extension "FormPilot" (the "Extension"), provided by the developer Ramune (the "Developer"), handles user information.

2. Information We Handle

To provide its features, the Extension may collect and use the following information.

(1) Profile information you enter

  • Personal information such as your name, email address, phone number, and address
  • Any custom fields you choose to add

This information is used solely to auto-fill web forms.

(2) Form information on websites

  • The structure of form elements on the page you are viewing (input, select, textarea) — labels, attributes, and field types
  • Form values you capture when you use the "Save Current Form" feature

Form structure information is used only to determine field types when the AI auto-fill feature runs.

(3) Information stored locally

  • Profile information you have registered
  • Form data saved per website
  • Settings (language, theme)
  • A randomly generated device identifier used for usage limiting and abuse prevention

This information is stored only on your device using the Chrome Storage API (chrome.storage.local).

3. Purpose of Use

We use the information collected only for the following purposes.

  • Providing the web form auto-fill feature
  • Restoring saved form data
  • Automatic detection of form field types using AI
  • Saving and restoring user settings
  • Preventing abuse and enforcing daily usage limits

4. Transmission to External Services

When you use the AI auto-fill feature, the Extension sends the form's structure information (HTML metadata such as labels, attributes, and field types) to the Developer's proxy server, hosted on Cloudflare Workers, which forwards it to the Google Gemini API for analysis.

Important: Your personal information (name, email address, address, etc.) is NOT sent externally. Only the structure of the empty form is transmitted.

A randomly generated device identifier is also sent with each request to enforce usage limits and prevent abuse. This identifier is not linked to your personal identity.

No data other than the above is sent to any external server.

5. Disclosure to Third Parties

We will not disclose the information collected to third parties except in the following cases.

  • When required by law
  • When you have given your explicit consent

6. Third-Party Services

The Extension uses the Google Gemini API (accessed via the Developer's Cloudflare Workers proxy) for form field type detection. No data is sent to any other third-party service.

7. Permissions

The Extension uses the following Chrome permissions.

  • storage: To save your profile information, per-site form data, and settings
  • activeTab: To detect form fields on the current tab and perform auto-fill
  • scripting: To run the form detection and fill logic on the current page

These permissions are the minimum necessary to provide the Extension's features.

8. Data Storage

All data saved by the Extension is limited to your device (the Chrome storage area). The Developer does not independently collect or store your data. You can delete all stored data by uninstalling the Extension.
