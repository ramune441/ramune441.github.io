SubDuo Privacy Policy

Last updated: August 30, 2026

This Privacy Policy describes how the developer Ramune (the "Developer") handles user information in the Chrome extension "SubDuo — Dual Subtitles for Streaming" (the "Extension"). The Extension shows two subtitle languages at once on Prime Video, YouTube, Netflix and Disney+.

In short: SubDuo has no server. It collects nothing, sends nothing, and contains no analytics, advertising or third-party code. Everything happens inside your browser.

1. Information the Extension handles

(1) Subtitle files of the title you are watching

  • To display two languages, the Extension reads the subtitle track list that the streaming site's own player receives for the current title, and fetches the corresponding subtitle files (TTML, WebVTT or the site's own caption format) from that site's own delivery servers.
  • On YouTube, the Extension additionally asks YouTube's own player API for the caption list of the video you are watching. This request is sent to YouTube without your cookies, so it is not tied to your YouTube account.
  • These files are parsed in your browser and drawn over the video. They are kept only in memory for the current tab and are discarded when the tab is closed.
  • The Extension does not read, record or transmit the video itself, the title name, your watch history, or anything else on the page.

(2) Settings stored locally

  • Your display settings: on/off, the two chosen languages, text size, position, alignment, text colors and transparency per line.
  • These are kept separately for each supported site, so Prime Video, YouTube, Netflix and Disney+ can each have their own setup.

These are stored with the Chrome Storage API (chrome.storage.sync). Chrome may sync them between your own devices when you are signed in to Chrome with sync enabled; the Developer has no access to them.

2. Information sent to external servers

None. The Extension makes no requests to any server operated by the Developer or any third party. The only network requests it makes are to the streaming site you are already using, for the subtitle files of the title you are already streaming — the same files that site's own player downloads.

3. Third-party sharing

The Developer never collects, sells or shares any user data, because none is collected. The Extension contains no advertising, tracking, or analytics.

4. Permissions

The Extension requests only the permissions needed for its features:

  • storage: saving your display settings for each site.
  • tabs: checking which supported site the current tab is on, so the popup can show that tab's detected subtitle languages and edit that site's settings.
  • scripting: re-attaching the Extension to already-open supported tabs after it is installed or updated, so you do not have to reload them.
  • Host access to the supported sites (primevideo.com and the Amazon stores listed on the product page, www.youtube.com, www.netflix.com, www.disneyplus.com): detecting subtitle tracks and drawing the overlay. The Extension does not run on any other site.

The Extension does not request access to your camera, microphone, location, browsing history, or clipboard.

5. Data retention and deletion

All data the Extension stores (settings and presets) is kept solely in your browser's Chrome storage area. The Developer does not store it anywhere. Uninstalling the Extension deletes all of it.

6. Children's privacy

The Extension collects no personal information from anyone, including children.

7. Contact

  • Developer: Ramune
  • Email: warload57@gmail.com

8. Changes to this policy

This policy may be revised in response to changes in the law or the Extension. The updated version will be published on this page with a new "Last updated" date.

SubDuo プライバシーポリシー

最終更新日: 2026年8月30日

本プライバシーポリシーは、開発者 Ramune（以下「開発者」）が Chrome 拡張機能「SubDuo — 動画配信の二言語字幕」（以下「本拡張機能」）において利用者の情報をどのように扱うかを定めるものです。本拡張機能は、Prime Video・YouTube・Netflix・Disney+ の字幕を2言語同時に表示するツールです。

要点: SubDuo にサーバーはありません。何も収集せず、何も送信せず、解析・広告・第三者のコードも含みません。すべてブラウザ内で完結します。

1. 本拡張機能が扱う情報

(1) 視聴中の作品の字幕ファイル

  • 2言語を表示するため、本拡張機能は各配信サイトのプレイヤーが受け取る現在の作品の字幕トラック一覧を読み取り、該当する字幕ファイル（TTML・WebVTT など、そのサイトの字幕形式）をそのサイト自身の配信サーバーから取得します。
  • YouTube では、視聴中の動画の字幕一覧を YouTube 自身のプレイヤー API に問い合わせます。この通信はCookie を送らずに行うため、利用者の YouTube アカウントとは結び付きません。
  • 取得した字幕はブラウザ内で解析し、動画の上に描画します。字幕はそのタブのメモリ上にのみ保持され、タブを閉じると破棄されます。
  • 動画そのもの、作品名、視聴履歴、ページ上のその他の情報を読み取り・記録・送信することはありません。

(2) ローカルに保存する設定

  • 表示設定: ON/OFF、選択した2言語、文字サイズ、表示位置、文字揃え、段ごとの文字色と透過度。
  • これらは対応サイトごとに独立して保存されるため、Prime Video・YouTube・Netflix・Disney+ で別々の設定を持てます。

これらは Chrome Storage API（chrome.storage.sync）で保存されます。Chrome にサインインして同期を有効にしている場合、Chrome が利用者自身の端末間で同期することがありますが、開発者はこれらにアクセスできません。

2. 外部サーバーへ送信する情報

ありません。 本拡張機能は、開発者または第三者が運営するいかなるサーバーにもリクエストを送りません。行う通信は、いま利用している配信サイトから視聴中の作品の字幕ファイルを取得することだけで、これはそのサイトのプレイヤー自身がダウンロードするものと同じファイルです。

3. 第三者への提供

開発者は利用者のデータを収集していないため、販売・提供することもありません。本拡張機能には広告・トラッキング・解析はいっさい含まれていません。

4. 権限

本拡張機能が要求する権限は、機能の提供に必要な最小限のものです。

  • storage: サイトごとの表示設定の保存。
  • tabs: 現在のタブがどの対応サイトかを確認し、ポップアップにそのタブで検出した字幕言語を表示し、そのサイトの設定を編集するため。
  • scripting: インストール・更新の後、すでに開いている対応サイトのタブへ本拡張機能をつなぎ直すため（再読み込みを不要にするため）。
  • 対応サイトへのアクセス（primevideo.com および製品ページに記載の Amazon 各国ストア、www.youtube.com、www.netflix.com、www.disneyplus.com）: 字幕トラックの検出とオーバーレイの描画。これ以外のサイトでは動作しません。

カメラ・マイク・位置情報・閲覧履歴・クリップボードへのアクセスは要求しません。

5. データの保存期間と削除

本拡張機能が保存するデータ（設定とプリセット）は、利用者のブラウザの Chrome ストレージ領域にのみ保持されます。開発者はこれをどこにも保存しません。本拡張機能をアンインストールすると、これらはすべて削除されます。

6. 子どものプライバシー

本拡張機能は、子どもを含むいかなる利用者からも個人情報を収集しません。

8. 本ポリシーの変更

法令や本拡張機能の変更に応じて、本ポリシーを改定することがあります。改定後の内容は本ページに新しい「最終更新日」とともに掲載します。
