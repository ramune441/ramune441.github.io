FOREGROUND_SERVICE_SPECIAL_USE
特別用途のフォアグラウンドサービスの使用デモ How this app uses the special-use foreground service
1用途 / Purpose

集中の見守りプロセスを維持し、常駐の状況通知を表示するために使用します。

「使える時間」を稼ぐ集中タイマーとアプリブロックを、端末がスリープ・最適化されても止めないために、専用のフォアグラウンドサービスを実行します。

Used to keep the focus-monitoring process alive under battery optimization and to show an ongoing status notification — so the focus timer and app-blocking keep working in the background.

2開始トリガー / Trigger

アプリブロック（アクセシビリティ）を有効にすると、見守りサービスが開始します。

サービスはユーザーがこの機能を有効にしたときだけ起動し、無効にすると停止します。常時バックグラウンド実行ではありません。

The foreground service is started only when the user enables Ripen's app-blocking accessibility service, and stops when it is turned off.

3常駐通知 / Ongoing notification

サービスが「本日の状況」の常駐通知を表示します。

アプリを開かなくても、使える時間・今日の集中/達成・時間帯の残り回数がわかります。1分ごとに更新される進行中（消せない）通知です。

The service posts an ongoing "Today's status" notification — usable time, today's focus/achievements and remaining rounds — refreshed every minute.

4バックグラウンド継続 / Keeps running

画面を離れても、計測とブロックを継続します。

このサービスがプロセスを生かし続けるため、ホームに戻っても・画面を消しても、集中の計測と「使える時間」の消費・対象アプリのブロック判定が止まりません。

Because the service keeps the process alive, focus tracking, usable-time accounting and block enforcement continue even when the app is in the background or the screen is off.

5ブロック実行 / Enforcement

残り0分で対象アプリを開くと、ブロック画面を表示します。

使える時間がゼロのとき、生かし続けられたプロセスが前面アプリを検知し、対象アプリをそっとロックします。これがこのサービスの中心的な目的です。

When usable time is zero, the kept-alive process detects the foreground app and gently locks it — the core purpose of this service.

6停止 / Stops

機能を無効にすると、サービスも停止し、通知も消えます。

ユーザーがアクセシビリティを切れば、フォアグラウンドサービスは即座に停止します。ユーザーの制御下にあります。

Turning the accessibility feature off immediately stops the foreground service and removes the notification — fully under user control.
