# ページと素材の決定

## サイト構成
| パス | 種別 | 索引 | sitemap |
|---|---|---|---|
| `/` | ポータル（全プロダクト一覧） | index | yes |
| `/<product>/` | LP | index | yes |
| `/<product>/contact.html` | 問い合わせ | index | yes |
| `/<product>/privacy-policy.html` | プライバシーポリシー | index | yes |
| `/<product>/uninstall.html` | アンインストール理由アンケート | noindex | no |
| `/<product>/promo.html` `store-images.html` `icon-512.html` 等 | 録画・画像生成用 | noindex | no |
| `/sendready-chrome/<lang>/` | SendReady LP の言語別ページ（19 言語） | index | yes |
| `/sendready/contact.html` | 転送（→ `/sendready-chrome/contact.html`） | noindex | no |

プロダクト: FormPilot・足あとメーカー・SendReady（Chrome）・SubDuo・Ripen（Android）・Kura（Android）。

## LP 共通
- 構成は Hero → 対応先 → 課題 → 比較 → デモ → メリット → 機能 → 使い方 → 安全性 → 注意 → FAQ → CTA。
- 多言語は `i18n-lp.js`（言語の決め方は `?lang=` > localStorage `lp_lang` > ブラウザ言語）。**HTML の既定文は en 辞書と同じ文字列にする**（実行時に上書きされるので、ずれるとクローラだけが古い文言を見る）。
- YouTube 埋め込み（`#promo-video`）は表示言語の動画に切り替える。

## FormPilot の説明資料
- LP・使い方ガイド・プライバシー説明・問い合わせは拡張と同じ20言語に対応する。LP・ガイド・プライバシー説明は翻訳済みHTMLを配信し、各言語のcanonical・hreflangとサイトマップを持つ。
- 上限・プライバシー・対応範囲は拡張の決定に従う。「3秒」「誤入力ゼロ」「全フォームに完全対応」は約束せず、日次上限と入力結果の確認も説明する。
- ガイドのボタン名・操作説明・画面は実際の拡張から取り込む。資料の追加文は `formpilot/translations*.js`、機能説明は拡張のストア文、画面は拡張UIから生成する。
- チュートリアルは架空データの入力前後を手動で切り替える端末内のサンプル。AIやフォーム送信は実行せず、キーボードでも入力・復元・初期表示への切替ができる。
- 動画は各言語に紹介・操作説明の2本を用意し、実画面と字幕を現地語に揃える。1080pのMP4・字幕・ポスターを同じ言語ページに置き、自動再生せず、再生・シーク・字幕は閲覧者が操作する。
- ストアのローカライズ版プロモーション動画はYouTube上の言語別動画を指定する。アップロード素材は4K・30fpsのH.264 HighとステレオAACとする。
- YouTubeの紹介動画は実録版（25秒・20言語）で、つかみ（同じ入力の繰り返し）→ 名前 → 実演 → 締めの順に見せる。実演は各言語の拡張UIと架空の問い合わせフォームで、本物のAI入力・修正・保存・開き直し・復元を1回ずつ録画したものを使い、操作や結果を合成しない。
  - フォームには文字欄・セレクトに加えてラジオボタン（性別）・日付欄（生年月日、カレンダー付き）・チェックボックス（ニュースレター）を置き、AIが入力した直後にその3欄へ種類名のラベルを順に出す。
    - 注意: 文字欄だけのフォームでは、選択肢・チェック・日付も入ることが動画から伝わらない。
  - 早送りはAIの待ち時間で4倍まで、利用者の文字入力を含む場面で3倍まで、他は2.5倍以内。「3秒」「誤入力ゼロ」「全フォーム対応」は言わず、締めで送信前の確認を促す。
  - 注意: ポップアップは裏のタブで撮るため、クリック直前のコマではポインタが移動の途中で写る。クリックの前後はその前のコマを使う。
- 音は自作のBGMと控えめな効果音（クリック・入力完了・復元・場面転換・つかみの打鍵・ロゴ・締めのボタン）で、第三者の楽曲・音声サンプルを使わない。操作の音はBGMと同程度、打鍵と場面転換は背景程度とし、全体は約-16 LUFS・ピーク-1 dBTP以下。
  - 注意: 画面の出来事すべてに効果音を付けると（25秒で約50回）うるさい。
- 国別の入力指定を説明し、本人確認番号・他人の氏名・非対応の暦はカスタム項目で明示する。値を推測して作るとは説明しない。
- プライバシーは保存した値、AIへ送る構造とカスタム項目名、デバイスID・IPによる利用制限、Web計測と任意の問い合わせを区別する。英語の詳細ポリシーも参照できる。

## SendReady LP（`/sendready-chrome/`）
- **言語ごとに URL を持つ**: en はルート、他は `/sendready-chrome/<lang>/`。各ページは本文をその言語で生成済みで、実行時に訳し直さない（クローラが英語ブラウザとして描画しても、その言語で索引させるため）。言語セレクターはその言語のページへ移動する。
- ルートは拡張が `?lang=` 付きで開くため、従来どおりその場で言語を切り替える。使い方ページ（how-to.html）もその場で切り替える。
- title / description は検索語入り（`i18n-lp.js` の `seo_title` / `seo_desc`）。ja は「敬語」「ビジネスメール」「書き換え」「返信」「定型文」、他言語は「AI 書き換え（rewrite / reformuler / umschreiben …）」「メール返信」「テキスト展開・テンプレート」の語。
- 各ページは hreflang（全 20 言語＋ x-default=ルート）と、その言語の SoftwareApplication・FAQPage・BreadcrumbList を持つ。
- ウェブストアへのリンクは言語別の utm 付き（contract.md）。
- 言語は拡張 UI と同じ 20 言語。繁体字のコードは `zh-TW` で、`?lang=` とブラウザ言語の zh_TW / zh-HK / zh-MO / zh-Hant も zh-TW に寄せる（拡張は `zh_TW` で渡す）。お問い合わせページも同じ 20 言語。
- `/sendready/contact.html` は削除済み Android 版の旧問い合わせ URL。ストア公開中の古い拡張が持つため転送ページとして残す。

## SubDuo の素材
- 実操作版の紹介は実サイトと実拡張を録画し、二言語表示・位置とサイズ調整・一文単位の練習・語句保存・単語帳を約40秒で見せる。説明を流すだけにせず、操作の瞬間に画面を寄せ、キー・クリック・保存を注釈で示す。一文単位の練習は映像の下に字幕の行をカードで並べ、Dで次の行へ・Aで前の行へ送る（行き来して見せる）・Sで再生バーが先頭に戻る・Qで停止スイッチが入る・バーが行末に届いて止まる、をキー操作と同時に見せる。文字サイズはホイールで拡大と縮小の両方を実際に行い、拡張が実際に適用した刻みごとの倍率を表示する。
- 実操作版はUIと同じ20言語で作る。上段は映画の英語、下段・SubDuoのUI・見出しと注釈はその言語。作品に字幕がない言語（繁体字中国語・韓国語・ヒンディー語・インドネシア語・タイ語）は、近い言語の字幕（簡体字・日本語・スペイン語・日本語・簡体字）で撮り、代わりであることを画面に明記する。
  - 英語版は下段のスペイン語の語を保存する（UIと同じ言語の語には拡張が意味を出さないため）。
- 画面は録画のプレイヤーの中（単語帳はそのページ）だけを映す。関連動画のサムネイルや、ポインタを載せている間に出る操作バーの章タイトルは入れない。
- 実操作版の音は自作のBGMと効果音で、第三者の楽曲・音声サンプルを使わない。効果音は画面の出来事と同じ時刻に鳴らし、BGMとほぼ同じ大きさ（目立たせる場面でも数dB上まで）にする。埋もれさせず、うるさくもしない。音色は曲と同じ調の柔らかい楽器音（マリンバ・チェレスタ・軽いタップ）にし、生のノイズや音程が落ちる電子音は使わない。全体は約-16 LUFS・ピーク-1 dBTP以下、末尾はフェードアウト。
  - 注意: 効果音をBGMと同じ経路に流すと、BGMと一緒に下がって聞こえなくなる。
- 実演に使う作品は商用利用・編集を許諾した素材とし、作品名・著作権者・ライセンス・変更点を動画と付属クレジットに残す。第三者作品のおすすめや個人情報は収録範囲に入れない。
- 紹介動画はUIと同じ20言語を揃え、公開済み12言語を再利用し、不足8言語を追加する。既存の39.5秒の構成とBGMを保ち、画面内テキスト・字幕例の下段・投稿情報を翻訳する。
- 追加版は現在の5サービス対応と、利用者が「AIに聞く」を押した場合の語句・文脈の送信を案内する。アラビア語の本文は右から左、学習対象の字幕は自身の文字方向で表示する。
- ストア画像は拡張 UI と同じ20言語を持つ。各言語に紹介画像5枚とマーキー1枚を用意し、ブランドとサービス名だけの小タイルは共通とする。アンインストールアンケートは12言語。
- ストア画像は「困りごと → 解決」の型で、機能の羅列にしない。5枚は1回の視聴の流れ（2言語で観る → 聞き逃した行を取り戻す → 知らない語を調べる → 保存した語を復習する → 始め方）の順に並べる。字幕サンプルは上段＝原語・下段＝UI 言語。
- 各言語で同じ構成を使い、見出し・操作ラベル・語義・例文の訳を現地語にする。アラビア語の説明と操作画面は右から左、字幕と学習対象の語句は本文自身の文字方向で表示する。
- **「完全ローカル／何も送らない」とは書かない**（語句を調べたときは語句と字幕行を解説サーバーへ送るため）。「字幕はブラウザの外に出ない・送るのは調べた語句だけ」と書く。
- ストア掲載文（`subduo/store-listing.json`）は「要約 → できること → 対応サイト → 使い方 → プライバシー → 注意 → URL」の順。名前と概要は拡張の `_locales` が使われるので持たない。
- ストアの説明本文も拡張UIと同じ20言語に翻訳し、未翻訳の本文を英語で代用しない。追加言語を含む全言語の本文・権限・動作要件を検証し、保存後に各言語を選び直して原文と照合する。
- 掲載文で案内する対応言語数は拡張UIと一致させる。
- プライバシーポリシーは英語／日本語切替（`?lang=ja`）。権限の記述は manifest の permissions と一致させる。

## Ripen・Kura の素材
- Kura は写真や動画をプライベートに隠せることと、開く際の端末認証を、ストア掲載の短い説明・本文・画像・アプリ紹介で揃えて伝える。暗号化や独自 PIN は約束しない。
- Kura の掲載文と言語対応・画像の順序は `kura/store-listing.json` を正とする。アプリ紹介と画像の見出し・説明はアプリの翻訳から取り込んで一致させる。
- Kura のストア素材はアプリと同じ 20 言語を用意し、スペイン語・ポルトガル語の地域別掲載を含む 22 掲載先で使う。各言語に掲載文、携帯電話 8 枚（紹介・片付け・プライベート・ライブラリ・バックアップ・Google フォトからの移行・AI 加工・ボディと料理の加工）とフィーチャー画像を持つ。Google のロゴは使わない。
- ストア画像は「ユーザー自身の困りごと → 解決」の型。製品への疑いを見出しに置かない（カルーセルは大見出しだけ読まれ、不安だけが残るため）。
- Kura の端末内の文言はアプリの strings.xml そのもの、キャプションだけ別辞書。金庫の名前は改名中なので `{vault}` でアプリの文言を差し込む。価格は en=$、ja=円、他は USD 表記（現地通貨は Play が換算するので推測しない）。
- Kura の売りはオールインワン（写真のことが全部 1 つのアプリでできること）。紹介とフィーチャーグラフィックの一言、短い説明、本文の冒頭はこれを言い、機能の札 5 つをその中身として見せる。スワイプを主役にしない。
- Kura の LP も同じ売りで始め、各機能はその言語のストア画像で見せる。機能・無料の範囲・プラン・権限・送信の説明は Kura アプリの仕様に合わせ、暗号化や「何も送らない」は書かない。
- Kura の LP は日本語を HTML に持ち、英語を `kura/i18n-lp.js` に持つ（プライバシーポリシーと同じく `?lang=` > localStorage `kura_lang` > ブラウザ言語）。画像・紹介動画・Play のリンクも表示言語に合わせる → 両言語のキーの一致は `kura/lp.test.mjs` が確かめる。
- Kura の LP の画像は `kura/images/lp/` の WebP（ストア画像を縮めたもの）を使う。ストア画像の PNG を直接読むと 1 言語で 10MB を超えるため。

## 足あとメーカーの素材
- デモ画像・動画は実際の Pairs 画面のキャプチャ。会員の顔写真・名前・自己紹介は必ずぼかす。
- 連続稼働キャプチャは進捗をリセットせずに撮る（重複訪問になるため進捗リセットは禁止）。

## 問い合わせ・アンケート
- 各ページは成功をその場に表示する（AJAX 送信）。選択肢は英語の正規値で送り、表示だけ翻訳する。
- アンインストールアンケートは詳細欄を必須にする。
