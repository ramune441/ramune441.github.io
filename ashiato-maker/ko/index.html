처리한 프로필을 기억해 같은 사람을 반복하지 않습니다(앱과 실행 상태에 따라 다름).

🔒 데이터는 브라우저 안에만

설정과 방문 기록은 브라우저에 저장됩니다. 확장 프로그램은 이를 외부 서버로 보내지 않습니다.

사용 방법

3단계, 30초면 준비 끝

복잡한 설정이 필요 없습니다. 기본값이 들어 있어 설치 직후 바로 사용할 수 있습니다.

  1. Chrome에 추가

    Chrome 웹 스토어에서 추가하기만 하면 됩니다. 계정이나 로그인은 필요 없습니다.

  2. 데이팅 앱 열기

    Chrome에서 지원 앱의 웹사이트를 열면 오른쪽 하단에 컨트롤 패널이 나타납니다.

  3. 시작을 누르고 그대로 두기

    이게 전부입니다. 알아서 계속 진행합니다. 실행 중에는 브라우저 창을 앞에 표시해 두세요.

안전과 개인정보 보호

안심하고 사용하실 수 있도록 다음과 같이 설계했습니다.

🔒 개인정보를 수집하지 않음

개인정보는 일절 수집하지 않습니다. 모든 데이터는 브라우저에 로컬로 저장됩니다.

🖥 외부로 보내지 않음

외부 서버로 데이터를 보내지 않습니다. 제거하면 모든 데이터가 삭제됩니다.

⏱ 자연스러운 속도

대기 시간은 설정한 범위 안에서 무작위로 정해지므로, 일정한 기계적 간격으로 클릭하지 않습니다.

🔢 한도로 과사용 방지

총 한도로 비정상적으로 많은 활동을 막아 위험을 최대한 낮춥니다.

⚠ 사용 전 확인하세요

각 데이팅 앱의 이용약관에 위반될 수 있습니다. 계정이 정지될 가능성도 실제로 있으므로 사용 여부는 직접 판단해 주세요. 어떤 앱과도 제휴하지 않은 비공식 도구입니다. 본인 책임 하에 사용하세요.
