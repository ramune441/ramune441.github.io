Features

Features

Every feature is free. No in-app purchases.

🔄 Continuous mode

Keeps going until your limit. On Tinder, Badoo and OkCupid it likes card after card; on Japanese apps it reloads the search page every set number of people to load new profiles.

⏱ Adjustable delay

Set a minimum and maximum delay in seconds; each profile gets a random wait within that range, for a natural pace.

🔢 Total limit

Set a maximum total; it stops automatically when it gets there, so you never overdo it.

❤️ Auto-like

Sends regular likes automatically on Tinder, Badoo, OkCupid and Match. On Tokyo Calendar Date it can also like the profiles it visits.

📋 Skips duplicates

Profiles it has handled are remembered so the same person is not repeated (depending on the app and run state).

🔒 Stays in your browser

Settings and visit history are saved in your browser. The extension does not send them to any external server.

How to use

Three steps, ready in 30 seconds

No complicated setup. Presets are built in, so it works right after you install it.

  1. Add to Chrome

    Just add it from the Chrome Web Store. No account or sign-in needed.

  2. Open a dating app

    Open a supported app's website in Chrome and the control panel appears in the bottom-right corner.

  3. Press Start and let it run

    That's it — it keeps going on its own. Keep the browser window in the foreground while it runs.

Safety

Safety and privacy

Here is what we do so you can use it with peace of mind.

🔒 No personal data collected

No personal information is collected. All data is stored locally in your browser.

🖥 Nothing sent out

No data is sent to external servers. Uninstalling removes all of it.

⏱ Natural pace

The delay is picked at random within your range, so it never clicks at a fixed, mechanical interval.

🔢 Limits keep it in check

A total limit prevents unusually heavy activity and keeps the risk as low as possible.

⚠ Before you use it

This may violate each dating app's terms of service. Account suspension is a real possibility, so please decide for yourself whether to use it. This is an unofficial tool, not affiliated with any of the apps. Use it at your own risk.
